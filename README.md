## 🚀 Proyectos destacados

💼 [Portfolio personal](https://github.com/anaia26/Portfolio)

Desarrollo de mi primer portfolio personal utilizando Bootstrap como framework principal para el diseño y la maquetación de la web. También incorpora reglas personalizadas de CSS para adaptar determinados elementos y complementar los estilos y componentes proporcionados por Bootstrap.

Realizado individualmente para el módulo de Diseño de Interfaces Web de 2.º curso del Ciclo Superior de Desarrollo de Aplicaciones Web (DAW), en CPR Liceo La Paz, durante el curso 2024-2025.

Tecnologías: HTML5, CSS3 y Bootstrap.

🌐 [Ver portfolio](https://anaia26.github.io/Portfolio/html/index.html)


🧩 [El Rincón del Cubitero](https://github.com/anaia26/El-Rincon-del-Cubitero)

Desarrollo de una página web para una tienda ficticia de cubos de Rubik, realizado en colaboración con Diego Coello para la asignatura de Diseño de Interfaces Web del ciclo de Desarrollo de Aplicaciones Web.

El proyecto incluye una página de inicio, un catálogo de productos, páginas con información detallada, formularios de registro e inicio de sesión y una sección de contacto.

También se trabajó especialmente la accesibilidad web mediante HTML semántico, atributos ARIA, contrastes adecuados y un diseño adaptable a diferentes dispositivos. Para comprobarla se utilizaron herramientas como Lighthouse, NVDA y WAVE.

Tecnologías y herramientas: HTML5, CSS3, JavaScript y Bootstrap.


🎙️ [Podcast ColorMind](https://github.com/anaia26/Podcast-ColorMind)

Proyecto realizado en colaboración con Diego Coello para la asignatura de Diseño de Interfaces Web del ciclo de Desarrollo de Aplicaciones Web.

El trabajo consistió en la preparación y grabación de un podcast sobre la colorimetría aplicada al diseño de páginas web, tratando aspectos como la psicología del color, las combinaciones cromáticas y su influencia en la experiencia del usuario.

Para presentar el podcast, también desarrollamos una página web utilizando HTML, en la que integramos el contenido y permitimos reproducir directamente el audio.

Este proyecto me permitió combinar la creación de contenido multimedia con el desarrollo web, poniendo en práctica conocimientos de HTML y diseño de interfaces, además de trabajar habilidades de comunicación y divulgación tecnológica.

Tecnologías: HTML5, CSS, CSS Flexbox y herramientas de grabación y edición de audio.
